# 💼 Portfólio - Magnum Santos

Portfólio profissional desenvolvido em **React + TypeScript** como projeto final do curso de Engenharia Front-End da EBAC.

## 🚀 Tecnologias

* React
* TypeScript
* Vite
* CSS Modules
* React Icons

## 📂 Projetos

### Luxury Wheels API

API REST desenvolvida com Python, Flask, SQLite e autenticação JWT.

### Portal Viagens

Aplicação React para pesquisa de destinos turísticos com interface responsiva.

### Next Blog IBAC

Blog desenvolvido em Next.js 15 utilizando App Router, rotas dinâmicas e SEO.

### Lista de Tarefas

Projeto React/Next.js com Jest, React Testing Library e GitHub Actions.
